# 12. 광고 환불 정책 (오너 확정 2026-07-30)

**환불하지 않는다.** 광고는 결제 즉시 노출이 시작되는 상품이고, 채용이 일찍 끝난 것은
구매 목적을 달성한 것이지 상품 하자가 아니다.

| 상황 | 처리 |
|---|---|
| 구매자 사정(채용 완료·마음 변경) | 환불·이월 **없음** |
| 회사 귀책으로 노출 안 됨 | 그만큼 **기간 연장 또는 환급** |
| 회원이 광고 중인 공고를 직접 삭제·마감 | 남은 기간 소멸(삭제 확인창에 이미 경고) |

적은 곳 네 군데 — 결제 버튼 위(AdPurchase) · 이용약관 제9조 · 영수증 하단 · 결제내역 하단.
**포트원 취소 API 연동은 하지 않는다**(쓸 일이 없다). 도메인 연결 후에도 그대로.

# 13. 워크넷(외부 수집) 공고 정책 (오너 확정 2026-07-30)

**우리는 관여하지 않는다.** 외부 공고 지원은 원본 사이트에서 이뤄지고, 널스넷은 접수·기록·중개를
하지 않는다. 지원 내역에도 남지 않으며 화면이 그렇게 말한다.

**유일한 관여**: 이력서를 등록한 간호사 회원만 원본 사이트로 나갈 수 있다.

| 보는 사람 | 화면 |
|---|---|
| 비로그인 | "원본 사이트에서 지원합니다. 널스넷 회원(간호사)만 이동할 수 있습니다" + 로그인 |
| 병원 회원 | "외부 공고 지원은 간호사 회원만" |
| 간호사 · 이력서 없음 | "이력서를 등록하면 이동할 수 있습니다" + 이력서 작성(작성 후 이 공고로 복귀) |
| 간호사 · 이력서 있음 | 원본 사이트에서 지원(새 창) + "지원 내역에는 남지 않습니다" |
| 원본 링크 없음 | 연락처가 **있을 때만** 채용 문의를 가리킨다 |

외부 지원을 기록하는 기능은 만들지 않는다.

> 이유: 아래 근거는 "구 널스넷이 그러고 있으니 따라간다" 였는데, 그건 우리가 원한 방침이
