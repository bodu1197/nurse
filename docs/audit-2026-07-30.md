# 12. 광고 환불 정책 (오너 확정 2026-07-30)

**환불하지 않는다.** 광고는 결제 즉시 노출이 시작되는 상품이고, 채용이 일찍 끝난 것은
구매 목적을 달성한 것이지 상품 하자가 아니다.

| 상황 | 처리 |
|---|---|
| 구매자 사정(채용 완료·마음 변경) | 환불·이월 **없음** |
| 회사 귀책으로 노출 안 됨 | 그만큼 **기간 연장 또는 환급** |
| 회원이 광고 중인 공고를 직접 삭제·마감 | 남은 기간 소멸(삭제 확인창에 이미 경고) |

적은 곳 네 군데 — 결제 버튼 위(AdPurchase) · 이용약관 제9조 · 영수증 하단 · 결제내역 하단.
**포트원 취소 API 연동은 하지 않는다**(쓸 일이 없다). 도메인 연결 후에도 그대로.

# 13. 워크넷(외부 수집) 공고 정책 (오너 확정 2026-07-30)

**우리는 관여하지 않는다.** 외부 공고 지원은 원본 사이트에서 이뤄지고, 널스넷은 접수·기록·중개를
하지 않는다. 지원 내역에도 남지 않으며 화면이 그렇게 말한다.

**유일한 관여**: 이력서를 등록한 간호사 회원만 원본 사이트로 나갈 수 있다.

| 보는 사람 | 화면 |
|---|---|
| 비로그인 | "원본 사이트에서 지원합니다. 널스넷 회원(간호사)만 이동할 수 있습니다" + 로그인 |
| 병원 회원 | "외부 공고 지원은 간호사 회원만" |
| 간호사 · 이력서 없음 | "이력서를 등록하면 이동할 수 있습니다" + 이력서 작성(작성 후 이 공고로 복귀) |
| 간호사 · 이력서 있음 | 원본 사이트에서 지원(새 창) + "지원 내역에는 남지 않습니다" |
| 원본 링크 없음 | 연락처가 **있을 때만** 채용 문의를 가리킨다 |

외부 지원을 기록하는 기능은 만들지 않는다.

# 17. 커뮤니티 접근 규칙 (오너 확정 2026-07-30)

> "메뉴 카테고리는 보이게 해라 — 리뷰와 게시판. 단 **이력서를 작성한 간호사 회원만** 쓰고 보고

| 대상 | 메뉴 노출 | 읽기·쓰기·수정·삭제 |
|---|---|---|
| 비로그인 | **보인다** | 안내 화면(CommunityGate) |
| 간호사 · 이력서 없음 | **보인다** | 이력서 등록 안내 |
| 간호사 · 이력서 있음 | 보인다 | **전부 가능** |
| 병원 회원 | **보인다** | 간호사 전용임을 안내 |
| 관리자 | 보인다 | 열람·모더레이션(리뷰 작성은 제외 — 평점 오염 방지) |

**메뉴를 감추지 않는 이유**: 감추면 그런 기능이 있는 줄도 모른다. 못 쓰는 이유는 들어간 화면에서 말한다.

**강제 지점 (앱 + DB 이중)**
- 앱: `getCommunityAccess` / `requireCommunityMember` — 화면과 서버 액션 전부
- DB: `is_community_member()` 가 select·insert·update **에 더해 이제 delete 에도** 걸린다
  (마이그레이션 `20260730140000`, DB 적용 완료). 관리자는 `or is_admin()` 으로 자기 글을 지울 수 있다 —
  기존 admin 정책(insert·update)과 같은 모양으로 맞췄다.
- ⚠️ 이력서를 지우면 그 순간 **자기 글·리뷰도 못 고치고 못 지운다**(글 자체는 남는다).
  이력서 삭제 확인창에 그 사실을 적었다.

## ⚠️ 색인 범위가 바뀌었다 — 기록해 둔다

홈(`/`)은 canonical `/` · sitemap priority 1 로 **색인되는 페이지**다. 거기에 인재 카드가 실리면서,
`/talent` 의 noindex 가 막는 것은 이제 **그 URL 뿐**이고 카드 내용은 검색엔진에 들어간다.
프로젝트가 적어둔 "인재정보는 검색엔진에 절대 올리지 않는다"는 이 범위에서 더 이상 사실이 아니다 —
`constants.ts` · `talent/page.tsx` · `sitemap.ts` 주석을 사실대로 고쳤다.

**완화**: 가장 강한 식별자인 **자기소개(자유서술)만 홈 카드에서 뺐다**(`TalentCard hideIntro`).
`line-clamp` 는 CSS 로 한 줄만 보이게 할 뿐 문자열 전체가 HTML 에 실리기 때문이다.
제목·경력·희망조건·성별·나이는 그대로 나간다. 자기소개까지 노출하려면 `hideIntro` 한 단어만 지우면 된다.
이름·휴대폰·이메일·사진은 홈에서도 `/talent` 와 **같은 게이트**(광고 중인 병원)로 막혀 있다.
